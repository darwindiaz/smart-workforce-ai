📚 Glosario del Dominio (versión 0.1)
| Concepto | Definición |
| --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Conciliación Bancaria | Proceso de comparar los movimientos registrados por la empresa con los registrados por el banco para asegurar que representan la misma realidad financiera. |
| Movimiento Bancario | Registro de una transacción proveniente del extracto bancario. |
| Movimiento Contable | Registro de una transacción proveniente de la contabilidad de la empresa. |
| Coincidencia | Relación entre un movimiento bancario y uno contable que cumplen las reglas de conciliación. |
| Diferencia | Situación en la que un movimiento no puede conciliarse automáticamente y requiere revisión. |
| Extracto Bancario | Documento emitido por el banco que contiene todos los movimientos de una cuenta. |
| Libro Auxiliar | Registro interno de movimientos contables utilizado para comparar con el extracto bancario. |
| Partida Conciliatoria | Movimiento o diferencia que impide la conciliación automática y requiere explicación, ajuste o seguimiento. |
